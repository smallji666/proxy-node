# proxy-node cn-direct
# 国内直连域名清单(远程更新源)。proxy rule update 会把它拉到
# /etc/proxy-node/remote-direct.txt, 与脚本内置清单合并去重后渲染进三端订阅
# (Shadowrocket / Clash / sing-box)。改完这份文件, 用户执行 proxy rule update
# 即可生效, 不用重装。
#
# 收录标准: 只收 100% 确定境内、且 DNS 解析落在中国大陆的服务。
# 绝不收境外域名 —— 一个境外域名进这份名单, 它的 DNS 就会走国内明文,
# 属地检测立刻看到中国运营商, 比多漏几个国内站严重得多。
# 一行一个域名, # 开头是注释。单段后缀 cn 由脚本内置(这里不写, 格式校验不收单段)。
