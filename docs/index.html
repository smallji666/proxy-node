为什么不用跳过证书验证

Hysteria2 基于 QUIC，必须完成 TLS 握手。裸 IP 申请不到公共证书，所以多数脚本让你勾选「跳过验证」——那等于完全不验证对端身份，链路上任何人都能冒充你的服务器。

本脚本部署时会算出证书公钥指纹，用 pinSHA256 固定进客户端配置。证书可以是自签的，但指纹只能来自你那台机器。

注意：Shadowsocks-2022 无 TLS；AnyTLS / TUIC 的分享链接标准里没有指纹字段，只能 insecure=1。这三个协议请优先导入订阅里的 singbox.json，那才是真正固定的配置。
